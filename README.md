# Farmer's Delight for Survivalcraft 农夫乐事（生存战争移植版）

基于 **Farmer's Delight 1.21.1 / 1.3.4**（作者 vectorwing，MIT License）移植到
**Survivalcraft 2.4 / SCAPI 1.9.5.1** 的内容模组。

## 内容

- **114 种物品**：食物、饮品、食材、汤、沙拉、甜点、5 种刀具、4 种种子。
- **28 个方块类**（含 1 个隐藏的合成代理）：
  - 炉灶（可点燃、提供热量）、烹饪锅（6 格食材 + 成品 + 容器，带进度条与 GUI）、煎锅
  - 切菜板（放食材 + 刀切割，产出刀工食材）
  - 木篮 / 竹篮 / 11 种木质橱柜（27 格容器 GUI）
  - 6 种作物箱、稻秆/米袋/草捆、绳索、安全网、绳栅栏/门、榻榻米、帆布地毯
  - 肥沃土壤、肥沃耕地、有机堆肥、蘑菇菌落
  - 4 种作物（卷心菜、洋葱、番茄、水稻）与 7 种野生作物 + 沙生灌木
  - 4 种派、6 种盛宴（可多次取食）
  - 68 种帆布招牌状态（17 色 × 站立/墙面/悬挂/墙挂）
- **配方**：
  - 66 个工作台配方（由 FD 的有序/无序配方转换）
  - 24 个烹饪锅配方
  - 53 个切菜板配方
  - 26 个熔炉/烟熏/营火配方（通过工作台代理方块供热匹配）
  - 碗、玻璃瓶、海带的基础配方
- **世界生成**：新生成区块的草地/沙地上生成 FD 野生作物；水稻只在近水处生成。
- **本地化**：英文 / 简体中文物品、方块、GUI 文本。
- **美术**：直接使用 Farmer's Delight 的 16×16 物品/方块贴图，打包进两张图集。

## 操作

- **炉灶**：手持燃料（木柴、煤炭等）右击点燃；空手右击熄灭。点燃的炉灶可为上方的烹饪锅供热。
- **烹饪锅**：右击打开 GUI，放入最多 6 种食材；锅下必须有点燃的炉灶/火/营火/岩浆块。烹饪完成后成品进入右侧成品格，碗/瓶子等容器进入容器格。
- **切菜板**：右击放入食材，再手持任意刀具右击切割，产物掉落在砧板上方。
- **煎锅**：放在热源上方，手持可熔炼食材右击，快速煎熟。
- **篮子/橱柜**：右击打开 27 格容器。
- **派/盛宴**：右击取用一份；取完后方块消失。
- **作物**：种子右击土壤/肥沃土壤种植；光照≥9 生长，肥沃土壤更快；水稻需要附近有水。

## 构建

```powershell
dotnet build FarmersDelightForSC.csproj -c Release
```

输出：`bin/Release/FarmersDelightForSC.scmod`。将 `.scmod` 放入游戏的 `Mods` 目录。

依赖：`.NET 10 SDK`、`SurvivalcraftAPI.Survivalcraft 1.9.5.1` NuGet 包。

## 与 Java 版的差异 / 已知限制

- 生存战争没有 Java 版的全部原版物品（金锭、下界合金、骨头、可可豆、甜浆果、蜂蜜等）。移植版加入了这些基础物品，但部分只能通过创造模式或后续扩展获得；依赖它们的少量配方可能无法在生存中完整闭环。
- 68 种帆布招牌使用 **1 个方块 + 17 色 × 4 安装方式** 表达，无自定义文字编辑。
- 橱柜/篮子已扩展为 27 格，与 Java 版一致。
- 切菜板上的食材没有独立 3D 模型，只有交互与掉落。
- 少量 Java 版配方使用了 NeoForge 复合/差集标签或生存战争不存在的原版材料，已跳过或替换；配方总数见上。
- 作物生长、堆肥成熟等做了适合生存战争 tick 的简化。
